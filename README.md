# YT Агент — Android-приложение для ведения YouTube-канала

Приложение подтягивает статистику вашего канала через YouTube Data API и передаёт её ИИ-агенту на базе Claude (Anthropic API). Агент анализирует цифры и выдаёт:

- **разбор канала**: что работает, что нет, приоритетные шаги;
- **идеи видео** с названием, крючком и форматом (Shorts или длинное);
- **план публикаций** на 2 недели с конкретными днями и временем в вашем часовом поясе;
- **советы по продвижению**: названия, превью, теги, Shorts, плейлисты, коллаборации;
- **чат**: любые вопросы по каналу с учётом данных.

На вкладке «Канал» без всякого ИИ показаны подписчики, медиана просмотров, вовлечённость, частота выхода роликов, а также лучшие день и время публикации, рассчитанные по вашим прошлым видео.

## Установка

1. Откройте раздел **Releases** этого репозитория на телефоне и скачайте `YT-Agent.apk` из последней сборки.
2. Откройте файл и разрешите установку из неизвестных источников.
3. В приложении на вкладке «Настройки» укажите:
   - канал (`@handle`, ссылку или ID `UC…`);
   - **ключ YouTube Data API**: console.cloud.google.com → новый проект → APIs & Services → включить *YouTube Data API v3* → Credentials → Create credentials → API key (бесплатно);
   - **ключ Anthropic API**: console.anthropic.com → API Keys (оплата по использованию).

Ключи хранятся только на телефоне.

## Сборка

APK собирается автоматически в GitHub Actions (`.github/workflows/build-apk.yml`) при каждом пуше. Локально: `./gradlew assembleDebug` (нужен Android SDK, JDK 17).

## Ограничения

- Публичный API отдаёт просмотры, лайки и комментарии, но не время просмотра, удержание и время активности зрителей. Для этого нужен вход через Google (YouTube Analytics API), это следующий шаг.
- Лучшее время рассчитывается по результатам ваших прошлых публикаций, поэтому на канале с малым числом видео выводы приблизительные.
